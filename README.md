# N° — Focus Companion

A minimalist, futuristic daily focus and spending companion designed for personal clarity and flow.

## Highlights
- **Standalone PWA**: Installable directly to your iPhone / Android home screen as an edge-to-edge native app.
- **Voice Assistant**: Talk to N to plan your day, log activities, or record expenses with on-device speech feedback.
- **100% Offline Capability**: Runs seamlessly in zero-network conditions using local Service Worker caching, device speech synthesis, and `localStorage`.
- **Dynamic Scheduling**: Automatically shapes priority focus blocks, short breaks, and commitment windows.
- **Spending Guide**: Track needs vs. wants against your daily allowance with real-time progress indicators.

## Running Locally
Open `index.html` in any modern web browser or serve locally:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
